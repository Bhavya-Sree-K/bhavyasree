## ✨ Features

- 🎨 **Dark Theme UI** — Sleek, modern dark design with glowing accents and gradient effects
- 🌊 **Smooth Animations** — Powered by Framer Motion with scroll-reveal, float, and glitch effects
- 🖱️ **Interactive Elements** — Cursor glow, click ripple effects, and tilt card interactions
- 🌧️ **Matrix Rain Background** — Animated particle and matrix-rain background effects
- ⌨️ **Typing Animation** — Dynamic typing animation in the hero section
- 📱 **Fully Responsive** — Optimized for mobile, tablet, and desktop screens
- 📄 **Resume Download** — Direct resume download from the portfolio
- 🔗 **Social Links** — LinkedIn and GitHub quick links in the hero section
- 📬 **Contact Section** — Easy-to-use contact form for getting in touch

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/Bhavya-Sree-K/bhavyasree.git

# Navigate to the project directory
cd bhavyasree

# Install dependencies
npm install
# or
bun install
```

### Running Locally

```bash
# Start the development server
npm run dev
# or
bun dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production

```bash
npm run build
# or
bun run build
```
